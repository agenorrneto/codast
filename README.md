# 📦 About

This respository gathers all the scripts needed to reproduce the results from my PhD project, where I aim to develop a new genetic association test, named
CODAST (Contraint and Domain-based rAre variant aSsociation Test).


## 🌟 Why CODAST is important?

- It's a new approach for rare variant association tests, where informations about human populational genomics and structural biology are used
- etc.


## ℹ️ Overview

The project can be dived in three main steps:
1. Data mining
2. Association tests
3. Results interpretation

Thus far, scripts and analysis have been performed for step 1. This step is important for gathering data for step 2.

The scripts are organized as:
- scripts folder, which contains code needed data processing
- notebooks folder, which contains code needed for data analysis
