# 📦 About

This respository gathers all the scripts needed to reproduce the results from my PhD project, where I aim to develop a new genetic association test, named
CODAST (Contraint and Domain-based rAre variant aSsociation Test).


## 🌟 Why CODAST is important?

- It's a new approach for rare variant association tests, where informations about human populational genomics and structural biology are used


## ℹ️ Overview

The project can be divided in three main steps:
1. Data mining
2. Association tests
3. Results interpretation

Thus far, scripts and analysis have been performed for step 1. This step is important for gathering data for step 2.

The scripts are organized in two directories:
- `scripts` , which contains scripts used for data extraction and processing (e.g. amino acid coordinates conversion to genomic positions) and, 
- `notebooks` , which contains notebooks descring the analysis of data generated by `scripts` codes.


Thus far, the `scripts` directory contains the following files:
- `gcoord_translator.py`: this script gets genomic coordinates for annottated domains. As an input, it recieves an InterPro scanning result and it uses the informations from Ensembl, UniProt and EBI API for an accurate conversion from aminoacid positions to genomic positions.
